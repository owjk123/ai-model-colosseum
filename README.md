## 🎮 游戏简介

**AI模型三国杀** 是一款创新的在线卡牌对战游戏，将经典的三国杀机制与现代AI大模型主题完美融合。8个AI模型同场竞技，暗藏身份，合纵连横，最终只有一方胜出！

### 核心特色

- 🎯 **身份暗战** - 除主公外，其他身份未知，通过行为判断敌友
- ⚔️ **回合制对战** - 经典摸牌→出牌→弃牌流程
- 🃏 **丰富卡牌** - 基本牌、锦囊牌、装备牌多种组合
- 🦎 **肉鸽元素** - 随机事件、击杀奖励、天赋选择
- 🤖 **智能AI** - AI角色根据身份自主决策
- 🎨 **精美界面** - 现代化UI设计，流畅动画效果

## 📋 游戏规则

### 身份系统

| 身份 | 标识 | 目标 |
|------|------|------|
| 🏛️ 平台方（主公） | 公开 | 消灭所有挑战者和卧底 |
| 🛡️ 维护者（忠臣） | 暗置 | 保护平台方存活 |
| ⚔️ 挑战者（反贼） | 暗置 | 击杀平台方 |
| 🎭 卧底（内奸） | 暗置 | 成为最后存活者 |

### 人数配置

- **8人局**: 1平台方 + 2维护者 + 3挑战者 + 2卧底
- **6人局**: 1平台方 + 1维护者 + 2挑战者 + 2卧底
- **4人局**: 1平台方 + 1维护者 + 1挑战者 + 1卧底

### 回合流程

1. **摸牌阶段** - 摸2张手牌
2. **出牌阶段** - 可出多张牌（受英雄技能限制）
3. **弃牌阶段** - 手牌超过HP上限则弃牌

## 🃏 卡牌类型

### 基本牌

| 卡牌 | 效果 |
|------|------|
| ⚔️ 推理攻击 | 对范围内1人造成1点伤害，每回合限出1张 |
| 🛡️ 自我辩护 | 抵消1次推理攻击 |
| 💚 模型更新 | 回复1点HP，或濒死时自救 |

| 卡牌 | 效果 |
|------|------|
| 🚫 API限流 | 弃掉目标1张手牌 |
| 📤 参数泄露 | 获取目标1张手牌 |
| 💥 全网评测 | 对所有其他角色造成1点伤害 |
| 🔧 紧急补丁 | 抵消1张锦囊牌 |
| 🤝 开源运动 | 所有角色回复1HP |
| ☠️ 数据投毒 | 与目标轮流出推理攻击，先不出的受1伤害 |
| 🔗 推理链 | 摸2张牌 |
| 🎭 模型蒸馏 | 令目标对另一目标出推理攻击 |

### 装备牌

| ⚡ TPU阵列 | 武器 | 攻击范围+1 |
| 🛡️ RLHF护盾 | 防具 | 需2张攻击才受伤 |
| ⚖️ 对齐训练 | 防具 | 需2张攻击才受伤 |

## 🦎 肉鸽元素

### 随机事件（每3回合触发）

- 📦 新版本发布 - 所有人摸2张牌
- 💧 训练数据泄露 - 所有人随机弃1张牌
- ⛔ GPU短缺 - 下回合所有人摸牌-1
- 💚 API免费额度 - 所有人回复1HP
- 💀 模型下线 - 随机1名角色扣2HP
- 📊 基准测试 - 攻击牌最多的人摸2张
- ⚠️ 对齐审查 - 所有锦囊牌本回合无效
- 🚀 开源突破 - 所有人获得1张随机装备牌

### 击杀奖励

击杀其他角色后，从3个随机天赋中选择1个：

- 📈 参数扩展 - HP上限+1，回复1HP
- ⚡ 推理加速 - 每回合可多出1张推理攻击
- 💾 缓存命中 - 摸牌阶段多摸1张
- 🔄 数据飞轮 - 每次造成伤害摸1张牌
- ⚔️ 对抗训练 - 受到伤害时50%概率反弹1点
- 👁️ 知识蒸馏 - 可查看攻击你的人的手牌
- 📚 多任务学习 - 手牌上限+2
- 🔧 指令微调 - 将1张手牌变为任意基本牌（每回合1次）

### 全局修饰词（开局随机）

- ⏱️ 低延迟 - 攻击范围+1
- 📝 长文本 - 手牌上限+1
- 🔥 高并发 - 每回合多摸1张牌
- 📉 资源受限 - HP-1
- 🌱 开源生态 - 装备效果翻倍

## 🚀 开始游戏

1. 克隆或下载本项目
2. 直接在浏览器中打开 `index.html`
3. 选择参与人数（4/6/8人局）
4. 选择你的英雄
5. 点击"开始游戏"开始对战！

## 📱 响应式支持

游戏支持桌面和移动设备，移动端会自动调整布局以适应屏幕大小。

## 🎮 操作说明

### 出牌

1. 点击手牌选中
2. 点击目标角色出牌
3. 再次点击手牌取消选中

### 使用技能

点击右下角的技能按钮使用英雄技能

### 结束回合

点击"结束回合"按钮结束当前回合
